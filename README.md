# Business-Card🧐
This is What I completed Via HTML &amp; CSS

A focused CSS exercise exploring image styling and motion through a continuous floating animation. 😎


Features🤓
Custom @keyframes animation using translateY() to move an image up 15px and back.

Three-second animation loop with ease-in-out timing.

Image styling with a fixed width and a soft box shadow.

Transition declarations for transform, opacity, and filter.

Page-level spacing and font styling.

Skills Practiced🤖
CSS selectors, keyframe animations, transforms, transitions, and visual styling.
